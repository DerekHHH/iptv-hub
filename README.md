# 我的电视源 · IPTV 源聚合与自愈工具

> 一个"配一次、长期不用管"的电视直播源工具。
> GitHub 自动帮你抓源、测活、优选，电视端只需要粘**一个固定链接**。

**不用买服务器、不用装软件、不用写代码、完全免费（公开仓库）。**

---

## 这个工具到底帮你做了什么

网上的 IPTV 源过几天就失效，手动整理 m3u 又累。这个工具把它变成自动的：

| 它做的事 | 说明 |
|---|---|
| 🔍 自动抓源 | 每 6 小时从 5~6 个公开上游（iptv-org 等）拉取最新列表 |
| 💓 自动测活 | 对每一条地址并发探测，能连上、能拿到真实流数据才算"活" |
| 🏆 自动优选 | 每个频道保留**最多 3 个**存活源（分辨率高的优先、延迟低的优先） |
| 📄 自动生成 | 产出 TXT / M3U 播放列表 + EPG 节目单 |
| 🛡️ 自动兜底 | 上游大面积失败时**不覆盖**上一版，旧列表继续可用 |
| 🌐 自动发布 | 产物发布到 GitHub Pages，给你固定网址，电视端配一次就够 |

## 一、5 分钟上手（照着点就行）

### 第 1 步：Fork 这个仓库

1. 打开本仓库页面（你现在看的这一页）。
2. 右上角点 **Fork** → 下一页点 **Create fork**。
3. 等几秒，你会得到一个"你自己的"仓库，地址形如：
   `https://github.com/你的用户名/iptv`

> Fork = 复制一份到你自己的账号下。所有自动更新都跑在你自己的仓库里，不占别人资源。

---

### 第 2 步：打开 GitHub Pages（一次设置，终身有效）

1. 在你自己的仓库里点 **Settings**（设置）。
2. 左侧菜单找到 **Pages**。
3. **Build and deployment** → **Source** 下拉框，选 **GitHub Actions**（不要选 "Deploy from a branch"）。
4. 不用点保存，选完就生效。

---

### 第 3 步：手动跑一次，生成第一版列表

1. 点仓库顶部的 **Actions**（动作）标签。
2. 左侧列表里点 **更新电视源**。
3. 右边点 **Run workflow** 按钮 → 再点绿色的 **Run workflow**。
4. 等大约 10 分钟（页面会自动刷新，变成 ✅ 就完成了）。

> 之后它会自己每 6 小时跑一次，你完全不用管。

---

### 第 4 步：拿到你的专属链接

跑完之后有两种方式拿链接：

**方式 A（推荐）：打开这个工具自带的网页**

`https://你的用户名.github.io/iptv/`

网页上会直接把三条链接列出来，每条旁边都有「复制」按钮，点一下就好。

**方式 B：直接拼地址**

| 用途 | 地址 |
|---|---|
| TXT 列表（最常用） | `https://你的用户名.github.io/iptv/txt/all.txt` |
| M3U 列表（部分播放器） | `https://你的用户名.github.io/iptv/m3u/all.m3u` |
| EPG 节目单 | `https://你的用户名.github.io/iptv/epg/epg.xml` |

**三种链接有什么区别？**

- **Pages 链接**（形如 `你的用户名.github.io/...`）：最稳最快，**优先用它**。
- **GitHub 原始地址**（形如 `raw.githubusercontent.com/...`）：最直接，国内有时打不开，打不开时换。
- **jsDelivr 镜像**（形如 `cdn.jsdelivr.net/gh/...`）：国内加速通道，内容每 12 小时同步一次，可能稍旧。

> 不想算？直接去网页版，三种链接都给你准备好了（首页「其他格式 / 备用链接」）。

## 二、电视端怎么填（三款主流播放器）

> 通用原则：**填 TXT 链接**最省事；播放器要求 M3U 时再填 M3U 链接。地址里**不要**带引号、空格。

### 1) DIYP 影音

1. 打开 DIYP → **设置**（齿轮）→ **直播源 / 自定义源**。
2. 选 **添加源** → 类型选 **TXT**（有的版本写「网络接口」）。
3. 名称随便写（比如"我的电视源"），地址粘贴第 4 步的 **TXT 链接**。
4. 保存 → 返回首页 → 等它加载完 → **重启一次 App**。

### 2) 影视仓 / TVBox 系

1. 打开影视仓 → **设置** → **配置地址**（或「接口地址」）。
2. 粘贴 **TXT 链接** → 确定。
3. 回到首页，右上角**切换/刷新**一次配置。
4. 如果它要求"直播"单独配置，把同一个 TXT 链接填到 **直播源** 处。

> TVBox 的配置支持 `名称,地址` 形式，本工具的 TXT 已经是标准格式，直接粘即可。
> EPG（节目单）：在播放器的「EPG 地址 / 节目单」里填第 4 步的 **EPG 链接**。

### 3) 其他播放器（PotPlayer / Kodi / TiviMate 等）

- 支持 M3U 的，填 **M3U 链接**。
- 支持 XMLTV 的，EPG 处填 **EPG 链接**。

## 三、一键更新按钮怎么用（可选）

等不及 6 小时？可以在网页上点一下就立刻重新构建。

1. 打开 `https://你的用户名.github.io/iptv/` → 顶部 **一键更新**。
2. 按页面提示生成一把 **GitHub 钥匙（Token）**：
   - 点页面上的「去生成 Token（免费）」。
   - **Repository access** 选 `Only select repositories`，只勾你 Fork 的这个仓库。
   - **Permissions** → 找到 `Actions` → 设成 `Read and write`（其余都不用给）。
   - 点 **Generate token**，复制那串 `github_pat_...`。
3. 粘到网页的输入框里，点 **保存**。
4. 回到「一键更新」页，点 **立即更新列表**，页面会显示四步进度。
5. 大约 10 分钟后显示 ✅，回到电视上重新加载一次列表就行。

**关于安全（重要）**

- 钥匙只存在**你自己这台设备的浏览器**里（localStorage），不会上传到任何服务器，也不会写进日志。
- 请像密码一样保管。**不要**把它发到群里、截图里、issue 里。
- 不用了随时点「清除」，或去 GitHub 设置里把那把钥匙删掉。

## 四、常见问题

**Q：电视上加载不出来 / 一直转圈？**
1. 确认链接能在电脑浏览器里打开（能看到一堆 `频道名,http://...` 或 `#EXTM3U`）。
2. 换个链接试：Pages 打不开就换「jsDelivr 镜像」或「GitHub 原始地址」。
3. 确认电视和电脑的网络能上网（有些电视盒子必须连 WiFi 才能加载网络源）。
4. 重启播放器，再重新加载一次列表。

**Q：某个台看不了？**
单个源失效很正常——所以每个频道都保留了最多 3 个备用源。播放器里如果第一个不行，手动切下一个源；列表本身会在下次构建时自动把死源换掉（最长 6 小时）。

**Q：列表多久更新一次？**
每 6 小时（北京时间 0/6/12/18 点）。想立刻更新就用「一键更新」按钮。

**Q：会不会花钱？**
不会。公开仓库的 Actions 和 Pages 都是免费的。本工具单次构建控制在 25 分钟以内，一天 4 次，远低于免费额度。

**Q：Actions 显示红色的 ❌ 怎么办？**
1. 点进去看是哪一步失败，"查看详细日志"。
2. 如果是抓取/测活超时，属于上游抖动，等下一次自动跑通常就好了（旧列表仍然可用，网页上会有黄色提示"数据为上次构建"）。
3. 如果是 `npm ci` 失败，删掉仓库里的 `package-lock.json` 里被手动改坏的部分，或直接 Fork 最新版。
4. **重要**：构建失败不会清空你的列表，旧的 txt/m3u 一直有效。

**Q：网页上「测源」检测出来的结果和电视上不一样？**
浏览器有跨域限制，读不到大部分源的真实状态。网页会明确标注「可达·浏览器受限」，这种结果**仅供参考**，精确结果以自动构建为准。

**Q：我能加自己的源吗？**
可以。编辑仓库根目录的 `custom/sources.txt`，按里面注释的格式一行一条 `频道名,地址`，保存后下次构建会合并进去，而且优先级最高。

**Q：我想改频道名单/分组？**
编辑 `src/data/channel-rules.ts`（频道归一规则表），或者改 `custom/sources.txt` 补源。改完手动跑一次 Actions。

## 五、本地开发（给想改代码的人）

需要 Node.js 20+。

```bash
npm install            # 装依赖（运行时零依赖，只有开发依赖）
npm run typecheck      # 类型检查
npm test               # 单元测试（完全离线）
npm run web:dev        # 本地起网页（http://127.0.0.1:5173）

MOCK_MODE=1 npm run validate:local   # 完全离线跑一遍完整流水线，产物写到 dist/
npm run build          # 真实联网跑一次（约 10 分钟）
npm run web:build      # 构建网页到 site/
npm run pages:assemble # 把 site/ + dist/ 装配成可发布的 pages-out/
```

目录结构：

```
src/            抓取 / 解析 / 归一 / 测活 / 优选 / 产物生成（TypeScript，无运行时依赖）
src/config.ts   所有阈值、并发、超时、路径常量（唯一配置中心）
web/            网页端（Vite + React + MUI + Tailwind，HashRouter）
dist/           数据产物（入库）：txt/all.txt、m3u/all.m3u、epg/epg.xml、stats.json
data/           状态记忆（入库）：blacklist.json、history.json
site/           网页构建输出（不入库）
pages-out/      Pages 站点装配目录（不入库）
tests/          单元测试 + 离线 fixture
custom/         用户自填源
```
