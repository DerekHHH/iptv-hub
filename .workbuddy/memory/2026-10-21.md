### 架构锁定点（后续改动必须遵守）
- Node 20 + TypeScript，`tsx` 直跑源码，运行时零依赖
- `dist/` 只放数据产物且入库；Vite root=`web/`、outDir=`site/`；CI 用 `scripts/assemble-pages.mjs` 装配到 `pages-out/` 再 deploy
- 网页 `base:'./'` + HashRouter（规避 Pages 子路径 404）
- 浏览器端测活三级阶梯：Range 请求 → no-cors 降级（`performance` 取延迟）→ 判死；**禁用 `<video>` 探测**；并发 8
- 25 分钟预算：候选上限 3000、Node 端并发 64、首跳 8s/子请求 4s、全局 deadline 17min
- 三道降级门（上游失败率 ≥50% / 候选源不足 / 频道数 < 上次 60%）+ 顶层异常兜底 → 只写 stale stats，不覆盖旧产物，`exit 0`
- 频道唯一标识用 ASCII slug；M3U `tvg-id` 与 EPG `<channel id>` 同为 slug
- 产物强制 UTF-8 无 BOM + LF；时区用 `new Date(ms+8h)` + `getUTC*`，不依赖 TZ
- 所有触网函数必须可注入 `fetchImpl`，保证 `npm test` 离线全绿
